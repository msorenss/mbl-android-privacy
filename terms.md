## About the app

MBL Android is an Android client for Media Box Lounge, published by Markus Robert Sörensson. These terms cover the Android app. You connect the app to an MBL server you choose. The operator of that server manages accounts, access, libraries and server availability.

## Using the app

Connect only to servers you own or have permission to use. Stream, download or cast media only when you have the right to do so. Keep your server credentials secure and follow any rules set by your server operator.

Features such as Live TV, WebTV, offline downloads and Google Cast depend on your server configuration, media, network and compatible devices. External sites and services may have their own terms. The app does not grant access rights to any media, external service or private server.
